# Sicherheit

## Sicherheitslücke melden

Bitte melde vermutete Sicherheitslücken über **GitHub Private Vulnerability Reporting**:
[Private Sicherheitsmeldung erstellen](https://github.com/leonatwork/M365-License-Architect/security/advisories/new).
Der Meldeweg ist auch unter **Security → Advisories → Report a vulnerability** erreichbar.

Veröffentliche keine Exploit-Details in öffentlichen Issues, Pull Requests oder Diskussionen.
Beschreibe in der privaten Meldung die betroffene Version bzw. den Commit, die Auswirkungen
und die Schritte zur Reproduktion. Füge keine Zugangsdaten oder personenbezogenen Daten bei.

Zuständig ist [@leonatwork](https://github.com/leonatwork).
